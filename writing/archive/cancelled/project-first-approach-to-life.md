# Project First Approach to Life

- Approach everything in life as a project.
- A project has to be finished in a quarter.
- Every quarter you pick a few projects that help you grow in personal and professional domains.

Extending the idea of learning projects to a much more generic idea of achieving anything in life, which leads to a more accountable version of the whole learning projects initiative.

### Principles to Scope a Project

- What is a Project ?
  - A clear act of doing something that can run for at max a quarter, and has a somewhat outcome or progression defined.
  - The outcome should be achievable in a quarter at max, for projects that run for longer, break it down into multiple projects that can be done over a quarter.
  - Projects undertaken in a quarter should be such that they can be closed in a quarter.

### Project Logistics

I have a bunch of draft projects, and I want to pick a bunch of them every quarter, and close them.

These projects are a mix of everything -- personal projects, work projects, projects that start off as personal ideas but turn into work projects, work projects that inspire ideas.
