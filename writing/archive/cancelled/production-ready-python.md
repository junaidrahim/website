# Production Ready Python

- What all do you need to make python production ready, esp for scripts in data pipelines (why not just do this in spark ffs)

  - Logging
  - Metrics
  - Memory Profiling
  - CPU Profiling
  - Unit Tests
  - E2E and Fuzz Tests
  - monorepo management
  - Config management -- something like cobra
  - Spill to disk
