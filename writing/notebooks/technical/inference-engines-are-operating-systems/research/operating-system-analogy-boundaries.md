# Operating-system analogy boundaries

## Findings

- `UNVERIFIED`: the request/process, token/work, KV-cache/virtual-memory, kernel/device-layer, isolation/accounting, and distributed/cluster mappings still need mechanism-level verification.

## Evidence and notes

- Compare each mapping to primary inference-engine documentation and operating-system sources.
- Record responsibilities that remain with the host operating system.

## What this means for the draft

- Preserve the explicit claim that this is a structural analogy. Do not imply that an inference engine replaces the host operating system.

## Loose ends

- Decide which weak mapping should be cut rather than defended.
